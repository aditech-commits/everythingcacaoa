# Images Directory — Everything Cacao GH Theme

This directory stores all high-resolution product images, hero banners, and cacao/chocolate photography assets.

## Recommended Structure

```
images/
├── hero/                # Full-width hero banner images (min 2000px wide)
│   ├── hero-home.jpg
│   ├── hero-collections.jpg
│   ├── hero-craft.jpg
│   ├── hero-journal.jpg
│   └── hero-concierge.jpg
├── products/            # Product catalog card images (800×800 square)
│   ├── nahar-72-dark.jpg
│   ├── nahar-85-obsidian.jpg
│   ├── nahar-nib-salt-70.jpg
│   ├── cherelle-45-milk.jpg

│   ├── logo-gold.svg
```

## Image Specifications

| Asset Type       | Format | Min Width | Aspect Ratio | Notes                           |
|------------------|--------|-----------|--------------|----------------------------------|
| Hero Banners     | JPG    | 2000px    | 16:9         | WebP versions recommended        |
| Product Cards    | JPG    | 800px     | 1:1 (square) | Consistent white/cream backdrop  |
| Journal Articles | JPG    | 1200px    | 16:9         | Lifestyle editorial feel         |
| OG Social Card   | JPG    | 1200px    | 1.91:1       | For meta sharing preview         |
| Logos (SVG)      | SVG    | Vector    | N/A          | Gold + Dark variants             |
